💡 使用说明

网关地址：http://localhost:8088

认证方式：JWT Token（通过 /user/login 接口获取）

// 请求示例
POST http://localhost:8088/bookshelf/list
Authorization: Bearer <your-token>
Content-Type: application/json

注意：所有需要认证的接口都需要在请求头中携带 JWT Token。 Token 格式：Bearer <token>
